# استخراج از مخزن پژوهشی `legal_chatbot` 🧩

گزارشِ بررسیِ مخزن <https://github.com/HamedJahantigh-git/legal_chatbot> (پروانهٔ MIT،
دارندهٔ حق‌نشر: Hamed Jahantigh ۲۰۲۴) و آنچه از آن به «کتابچه قانون ایران» **افزوده شده** است.

> قاعدهٔ کلی این مرحله: **فقط اطلاعاتِ واقعاً جدید** استخراج شد. هر آنچه پیش‌تر در برنامه
> یکپارچه بود، دوباره وارد نشد و هر عنوانِ مشابه/تکراری **شمارش شد و کنار گذاشته شد**.

## ۲. آنچه افزوده شد

### ۲.۱ عناوین قوانین و مقررات — ۲۸۰ عنوان تازه

- خروجی: `data/curated/law-title-index.json`
- شناسه‌ها: `title-index-001` … `title-index-280`، با `origin: "law-title-index"`
- این مدخل‌ها **فقط عنوان** دارند (بدون متن ماده‌ها) و در برنامه با برچسب «فقط عنوان»
  از «فقط شناسنامه» متمایز شده‌اند تا کاربر بداند متن ماده‌ها در دسترس نیست.
- برای هر عنوان، دستهٔ موضوعی، سلسله‌مراتب، نوع سند و کلیدواژه به‌صورت خودکار
  (و فقط از روی خودِ عنوان) برآورد شده است؛ توزیع نوع سند:

| نوع سند | تعداد |
| --- | --- |
| قانون | ۲۴۲ |
| لایحه قانونی | ۱۰ |
| ماده واحده | ۱۰ |
| آیین‌نامه | ۹ |
| اساسنامه | ۵ |
| معاهده بین‌المللی | ۴ |

### ۲.۲ نهادها، شوراها و مراجع — ۱۶۷ نهاد تازه

- خروجی: `data/curated/entities-extra.json`
- یک گروه تازه با شناسهٔ `councils-and-authorities` («شوراها، ستادها و مراجع صادرکننده»،
  ترتیب ۹) — پس از ۸ گروهِ موجود می‌آید تا هیچ مدخل موجودی تغییر نکند.
- شناسه‌ها: `authority-001` … `authority-167`
- این فهرست از **فرادادهٔ اسناد** به‌دست آمده (مرجع صادرکننده/مخاطب)، نه از فهرست رسمی؛
  ممکن است شامل نام‌های تاریخی یا ترکیبی باشد. در توضیح گروه در برنامه ذکر شده است.

### ۲.۳ آراء قضایی — ۱٬۹۹۸ رأی (دریافتِ اختیاری)

- خروجی: `public/data/v<نسخه>/cases/` (فهرست + ۱۰ قطعهٔ ۲۰۰تایی، حدود ۱۲٫۸ مگابایت)
- **در همگام‌سازی عادی برنامه دانلود نمی‌شود**؛ کاربر آن را از صفحهٔ «آراء قضایی» یا
  تنظیمات فعال می‌کند تا حجم نصب اولیه ثابت بماند.
- جست‌وجو روی یک فهرستِ ازپیش‌نرمال‌شده انجام می‌شود (بدون ایندکس‌سازی سنگین) تا روی
  موبایل روان باشد.
- متن هر رأی برای صرفه‌جویی در حجم تا ۲٬۵۰۰ نویسه نگه داشته شده و در صورت برش‌خوردگی،
  طول متن کامل و هشدارِ مربوط در صفحهٔ رأی نمایش داده می‌شود.
- ⚠️ این‌ها **آرای وحدت رویه نیستند**؛ آراء شعب‌اند و صرفاً جنبهٔ مطالعاتی دارند.

## ۳. آنچه وارد نشد و چرا

| ردیف | دلیل |
| --- | --- |
| ۹۳ عنوان قانون | از پیش در برنامه موجود بود (تطبیقِ عنوان دقیق / هم‌ارز / زیررشته‌ای / واژگانی) |
| ۴۳ عنوان قانون | نزدیک‌تکراری با عنوانی دیگر در خودِ منبع (مثل سه نسخهٔ «چاه‌های آب») |
| ۱۹ عنوان قانون | نامعتبر: کوتاه‌تر از ۸ نویسه، تک‌واژه‌ای، یا بدون پیشوند سند |
| ۳۲ نهاد | از پیش در برنامه موجود |
| ۲۹ نهاد | نزدیک‌تکراری در خودِ منبع |
| ۱۷۱ نهاد | رد شد: تک‌واژه‌ای («بانک‌ها»)، عمومی («احصائیه امور قضائی»)، یا نقش به‌جای نهاد («پادشاه وقت»، «نمایندگان اطاق صنایع و معادن») |
| ۱۸ متن کامل قانون | تکراری با `data/sources/lawcorpus/` |

**قواعد پالایش** (در `scripts/extract-legalchatbot.mjs`):

- نرمال‌سازی املا: حروف عربی `ي/ك/ة` → `ی/ک/ه`؛ یکسان‌سازی «آئین/ائین/ايين» → «آیین»؛
  ترمیمِ الفِ افتاده در منبع («اموزش» → «آموزش»، «ازاد» → «آزاد»)؛
  پیوستنِ واژه‌های نیم‌فاصله‌ای پرسامد («آیین نامه» → «آیین‌نامه»).
- حذفِ فاصله برای مقایسه: «قانون اداره تصفیه امور ورشکستگی» و «قانونادارهتصفیه امور ورشکستگی»
  یکی دانسته می‌شوند (منبع گاهی بی‌فاصله نوشته است).
- نهادها: یکسان‌سازی «هیئت/هيئة» → «هیات»، «مؤسسه» → «موسسه»، «مسئول» → «مسوول»، «تأمین» → «تامین».

## ۴. سامانهٔ ملی قوانین (qavanin.ir)

در این مرحله **دسترسی به qavanin.ir از محیط اجرا ممکن نبود**: پاسخِ سرور صرفاً یک صفحهٔ
میانجیِ انتقال («در حال انتقال به سایت مورد نظر هستید…») بود و محتوای قانونی قابل دریافت نبود.

بنابراین **هیچ داده‌ای از این سامانه استخراج نشد** و چیزی به‌نام آن جعل نشد.
برای تکمیلِ بعدی دو مسیر وجود دارد:

1. اجرای `scripts/scrape/scrape_qavanin.py` در محیطی که به سامانه دسترسی دارد،
   و قرار دادن خروجی در `data/sources/` (نگاه کنید به `scripts/scrape/README.md`)؛
2. یا تحویلِ فایل‌های HTML/خروجیِ گرفته‌شده از سامانه توسط کاربر.

## ۵. بازتولید

```bash
npm run sources:fetch        # دریافت منابع حجیم از codeload.github.com
npm run extract:legalchatbot # بازسازی law-title-index.json و entities-extra.json
npm run data:build           # ادغام در public/data (و ساخت مجموعهٔ آراء)
```

هر سه اسکریپت **idempotent** هستند: اجرای مجدد، خروجیِ یکسانی می‌سازد و چیزی را
دوباره وارد نمی‌کند.

## ۶. اعتبارسنجی

- `npm run data:validate` — ساختار، یکتایی شناسه‌ها، هم‌خوانی آمار با محتوا
- `npm run registry:verify` — اطمینان از اینکه هیچ عنوانِ جدیدی با مدخل‌های موجود تداخل ندارد
- `npm test` — ۳۳ آزمون خودکار شامل آزمون‌های تازهٔ
  «یکپارچگی داده»، «مجموعهٔ آراء قضایی» و «جست‌وجو»
