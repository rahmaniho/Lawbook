گزارشِ بررسیِ مخزن <https://github.com/HamedJahantigh-git/legal_chatbot> (پروانهٔ MIT،
دارندهٔ حق‌نشر: Hamed Jahantigh ۲۰۲۴) و آنچه از آن به «کتابچه قانون ایران» **افزوده شده** است.

> قاعدهٔ کلی این مرحله: **فقط اطلاعاتِ واقعاً جدید** استخراج شد. هر آنچه پیش‌تر در برنامه
> یکپارچه بود، دوباره وارد نشد و هر عنوانِ مشابه/تکراری **شمارش شد و کنار گذاشته شد**.

## ۲. آنچه افزوده شد

### ۲.۱ عناوین قوانین و مقررات — ۲۸۰ عنوان تازه

- خروجی: `data/curated/law-title-index.json`
- شناسه‌ها: `title-index-001` … `title-index-280`، با `origin: "law-title-index"`
- این مدخل‌ها **فقط عنوان** دارند (بدون متن ماده‌ها) و در برنامه با برچسب «فقط عنوان»
  از «فقط شناسنامه» متمایز شده‌اند تا کاربر بداند متن ماده‌ها در دسترس نیست.
- برای هر عنوان، دستهٔ موضوعی، سلسله‌مراتب، نوع سند و کلیدواژه به‌صورت خودکار
  (و فقط از روی خودِ عنوان) برآورد شده است؛ توزیع نوع سند:

| نوع سند | تعداد |
| --- | --- |
| قانون | ۲۴۲ |
| لایحه قانونی | ۱۰ |
| ماده واحده | ۱۰ |
| آیین‌نامه | ۹ |
| اساسنامه | ۵ |
| معاهده بین‌المللی | ۴ |

### ۲.۲ نهادها، شوراها و مراجع — ۱۶۷ نهاد تازه

- خروجی: `data/curated/entities-extra.json`
- یک گروه تازه با شناسهٔ `councils-and-authorities` («شوراها، ستادها و مراجع صادرکننده»،
  ترتیب ۹) — پس از ۸ گروهِ موجود می‌آید تا هیچ مدخل موجودی تغییر نکند.
- شناسه‌ها: `authority-001` … `authority-167`
- این فهرست از **فرادادهٔ اسناد** به‌دست آمده (مرجع صادرکننده/مخاطب)، نه از فهرست رسمی؛
  ممکن است شامل نام‌های تاریخی یا ترکیبی باشد. در توضیح گروه در برنامه ذکر شده است.

### ۲.۳ آراء قضایی — ۱٬۹۹۸ رأی (دریافتِ اختیاری)

- خروجی: `public/data/v<نسخه>/cases/` (فهرست + ۱۰ قطعهٔ ۲۰۰تایی، حدود ۱۲٫۸ مگابایت)
- **در همگام‌سازی عادی برنامه دانلود نمی‌شود**؛ کاربر آن را از صفحهٔ «آراء قضایی» یا
  تنظیمات فعال می‌کند تا حجم نصب اولیه ثابت بماند.
- جست‌وجو روی یک فهرستِ ازپیش‌نرمال‌شده انجام می‌شود (بدون ایندکس‌سازی سنگین) تا روی
  موبایل روان باشد.
- متن هر رأی برای صرفه‌جویی در حجم تا ۲٬۵۰۰ نویسه نگه داشته شده و در صورت برش‌خوردگی،
  طول متن کامل و هشدارِ مربوط در صفحهٔ رأی نمایش داده می‌شود.
- ⚠️ این‌ها **آرای وحدت رویه نیستند**؛ آراء شعب‌اند و صرفاً جنبهٔ مطالعاتی دارند.

## ۴. تکمیلِ خلأها: «بقیه اطلاعاتی که موجود نبود»

### ۴.۱ وضعیت دسترسی به qavanin.ir

**دسترسی به `qavanin.ir` از محیط اجرا مسدود است.** بررسیِ انجام‌شده:

| تلاش | نتیجه |
| --- | --- |
| `curl https://qavanin.ir` با User-Agent مرورگر | `SSL_ERROR_SYSCALL` — اتصال TLS قطع می‌شود |
| `curl https://www.qavanin.ir` | همان خطا |
| `raw.githubusercontent.com` | نیز مسدود است |

(فقط `github.com`، `codeload.github.com`، `api.github.com` و چند میزبان بستهٔ npm/pypi
در دسترس‌اند.) بنابراین **هیچ داده‌ای مستقیماً از این سامانه استخراج نشد و چیزی
به‌نام آن جعل نشده است.**

جست‌وجوی گیت‌هاب نیز هیچ «دادهٔ استخراج‌شده از qavanin.ir» پیدا نکرد — فقط چند
خزنده (مثل `hamid97a/Qavanin_crawler` و `softrebel/qavanin_crawler`) که صرفاً کد هستند.

### ۴.۲ مسیر جایگزینِ استفاده‌شده: IranLegalHUB

مجموعهٔ `GeekNeuron/IranLegalHUB` متونی دارد که از منابع رسمیِ همان سامانه استخراج شده‌اند
و روی گیت‌هاب با مجوز MIT منتشر شده‌اند. ممیزیِ دوبارهٔ این مخزن نشان داد **۶ سندِ
متن‌کامل** هست که برنامه نداشت:

| سند | ماده‌ها | وضعیت پیشین در برنامه |
| --- | --- | --- |
| قانون امور گمرکی (مصوب ۱۳۹۰، اصلاحات تا ۱۳۹۳) | ۱۶۵ | فقط عنوان (`title-index-086`) |
| قانون امور حسبی (مصوب ۱۳۱۹) | ۳۷۸ | فقط عنوان (`title-index-085`) |
| قانون خدمت وظیفه عمومی (مصوب ۱۳۶۳، اصلاحات تا ۱۳۹۶) | ۸۸ | فقط عنوان (`title-index-174`) |
| قانون الحاق موادی به قانون خدمت وظیفه عمومی (مصوب ۱۳۶۵) | ۶ | نبود |
| قانون کاهش مجازات حبس تعزیری (مصوب ۱۳۹۹) | ۱۵ | نبود |
| قانون تشدید مجازات مرتکبین ارتشاء، اختلاس و کلاهبرداری (مصوب ۱۳۶۴/اصلاح ۱۳۶۷) | ۸ | فقط شناسنامه |

**جمع: ۶۶۰ مادهٔ جدید به برنامه اضافه شد** (۶٬۶۱۸ → ۷٬۲۷۸ ماده؛ ۴۰ → ۴۶ سندِ دارای متن کامل).
سه مدخلِ «فقط عنوان» و یک مدخلِ «فقط شناسنامه» به «متن کامل» **ارتقا** یافتند و از فهرستِ
مربوطه حذف شدند تا تکراری ایجاد نشود.

عمداً وارد نشد: `laws_batch3_criminal_courts_1_2_law.json` (قانون تشکیل دادگاه‌های کیفری ۱ و ۲)
که در خودِ منبع **منسوخ** اعلام شده و جایگزین آن قانون آیین دادرسی کیفری است.

### ۴.۳ باگِ اتلاف داده که در این مسیر پیدا شد

تجزیه‌گرِ JSON پروژه (`parseHubJson`) فقط سطحِ اولِ `divisions` را می‌خواند و به
`subdivisions` (بخش → فصل → مبحث) نمی‌رفت. اثرِ آن روی اسناد تودرتو:

| فایل | سطح اول | واقعی | ماده‌های از‌دست‌رفته |
| --- | --- | --- | --- |
| `hosbi_law.json` | ۷۴ | ۳۷۸ | ۳۰۴ |
| `civil_judgment_enforcement_law.json` | ۳۵ | ۱۸۰ | ۱۴۵ |
| `customs_law.json` | ۴۶ | ۱۶۵ | ۱۱۹ |
| `constitution.json` | ۱۱۴ | ۱۹۱ | ۷۷ |
| `military_service_law.json` | ۴۴ | ۸۸ | ۴۴ |
| `criminal_courts_1_2_law.json` | ۸ | ۴۳ | ۳۵ |
| `islamic_penal_code_book_5_tazirat.json` | ۲۲۹ | ۲۶۰ | ۳۱ |

بررسی شد که **هیچ‌کدام از این فایل‌ها پیش از این در فهرستِ برنامه نبودند** (منبعِ
کانonicalِ آن‌ها `lawcorpus` است)، بنابراین این باگ روی دادهٔ فعلی اثری نداشته است؛
اما برای افزودنِ شش سندِ بالا باید رفع می‌شد که شد. آزمونِ بازگشت در
`tests/parse.test.mjs` از تکرار آن جلوگیری می‌کند.

### ۴.۴ برای تکمیلِ بعدی

1. اجرای `scripts/scrape/scrape_qavanin.py` در محیطی که به سامانه دسترسی دارد،
   و قرار دادن خروجی در `data/sources/` (نگاه کنید به `scripts/scrape/README.md`)؛
2. یا تحویلِ فایل‌های HTML/خروجیِ گرفته‌شده از سامانه توسط کاربر.

## ۵. بازتولید

```bash
npm run sources:fetch        # دریافت منابع حجیم از codeload.github.com
npm run extract:legalchatbot # بازسازی law-title-index.json و entities-extra.json
npm run data:build           # ادغام در public/data (و ساخت مجموعهٔ آراء)
```

هر سه اسکریپت **idempotent** هستند: اجرای مجدد، خروجیِ یکسانی می‌سازد و چیزی را
دوباره وارد نمی‌کند.

## ۶. اعتبارسنجی

- `npm run data:validate` — ساختار، یکتایی شناسه‌ها، هم‌خوانی آمار با محتوا
- `npm run registry:verify` — اطمینان از اینکه هیچ عنوانِ جدیدی با مدخل‌های موجود تداخل ندارد
- `npm test` — ۳۸ آزمون خودکار در چهار گروه:
  - `tests/data.test.mjs` — یکپارچگی داده (آمار، شناسه‌ها، قطعه‌ها، مجموعهٔ آراء، نهادها)
  - `tests/parse.test.mjs` — تجزیه‌گرها، به‌ویژه بازگشتی‌بودنِ `subdivisions`
  - `tests/search.test.mjs` — جست‌وجوی واقعی (MiniSearch روی ۷٬۲۷۸ ماده) و مسیر «ماده N قانون X»
  - `tests/unit.test.mjs` — متن فارسی، قالب‌بندی، محاسبه‌گر ارث و دیه
