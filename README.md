# کتابچه قانون ایران 📚⚖️

وب‌اپلیکیشن موبایلی (PWA) مطالعه، جست‌وجو و مرور قوانین و مقررات جمهوری اسلامی ایران —
**آفلاین، سریع و کاملاً محلی**.

> **توسعه نرم‌افزار:** [کارن سافت](https://karen-soft.ir)
>
> ⚠️ مرجع رسمی، **روزنامه رسمی جمهوری اسلامی ایران** و **سامانه ملی قوانین و مقررات (qavanin.ir)** است.
> این برنامه ابزار کمکی مطالعه و جست‌وجوست و برای استناد در مراجع قضایی باید متن رسمی بررسی شود.

## 🧱 پشته فناوری

- **Next.js 14 (App Router)** + TypeScript + Tailwind CSS (طراحی RTL، فونت Vazirmatn به‌صورت self-host)
- **Dexie (IndexedDB)** برای پایگاه‌داده محلی و همگام‌سازی دلتا بر پایه هش
- **MiniSearch** در **Web Worker** برای جست‌وجوی فوری متن + مسیر سریع «ماده ۱۰ قانون مدنی»
- **PWA**: `manifest.webmanifest`، Service Worker با کش پوسته/دارایی/داده، نصب روی صفحه اصلی، Background Sync
- **فونت**: Vazirmatn (SIL OFL)

### مسیرها و نصب‌شدن PWA

تنها مرجعِ basePath فایل `config/base-path.mjs` است و هر سه مصرف‌کننده از همان
می‌خوانند:

| مصرف‌کننده | چطور basePath را می‌گیرد |
| --- | --- |
| `next.config.mjs` | `resolveBasePath()` و انتقال آن به کلاینت با `env.NEXT_PUBLIC_BASE_PATH` |
| `public/manifest.webmanifest` | در زمان بیلد توسط `scripts/build-manifest.mjs` با همان basePath بازنویسی می‌شود |
| `src/lib/base-path.ts` (کلاینت) | `withBase()` برای ثبت Service Worker و لینک manifest/آیکون‌ها |
| `public/sw.js` | در زمان اجرا از آدرس خودش: `new URL('./', self.location)` |

Next.js فیلدهای `metadata.manifest` و `metadata.icons` را با basePath ترکیب
**نمی‌کند**؛ بدون این لایه، در استقرار زیرمسیر همهٔ این مسیرها به ریشهٔ دامنه
اشاره می‌کردند و ۴۰۴ می‌گرفتند — یعنی `start_url` بیرون از scope سرویس‌ورکر
می‌افتاد و کروم هرگز دکمهٔ «نصب» را فعال نمی‌کرد. آزمون‌های این مسیر در
`tests/pwa.test.mjs` هستند (سرویس‌ورکر واقعاً در یک context مجزا اجرا می‌شود).

> `npm run data:build` مجموعهٔ «آراء قضایی» را در صورت نبودِ فایل خام
> (`data/sources/cases/case.csv`) حذف نمی‌کند؛ نسخهٔ ثبت‌شده — حتی هنگام تغییر
> نسخهٔ داده — حفظ و به نسخهٔ جدید منتقل می‌شود.

| فرمان | کار |
| --- | --- |
| `npm run dev` | ساخت داده‌ها و اجرای dev server |
| `npm run build` | ساخت داده‌ها + بیلد تولیدی Next.js |
| `npm run data:build` | ساخت داده‌های عمومی از منابع خام (idempotent) |
| `npm run data:validate` | اعتبارسنجی داده‌ها (ساختار، نرمال‌سازی، ۲۵ آزمون صحت متنی، نبود ارجاع بیرونی) |
| `npm run registry:verify` | تطبیق «فهرست مرجع» با داده‌های ساخته‌شده (چه چیزی موجود/ناموجود است) |
| `npm test` | اجرای مجموعهٔ آزمون‌های خودکار (داده، تجزیه‌گرها، جست‌وجو، محاسبه‌گرها، متن فارسی) |
| `npm run verify` | اجرای کاملِ همهٔ بررسی‌ها: ساخت داده، اعتبارسنجی، تطبیق فهرست مرجع، نوع‌ها، لینتر و آزمون‌ها |
| `npm run icons:gen` | تولید آیکون‌های PWA از SVG (با Sharp) |
| `npm run typecheck` | بررسی نوع‌ها |
| `npm run scrape` | اجرای اسکریپت استخراج از سامانه ملی قوانین (نگاه کنید به `scripts/scrape/`) |

## ⚖️ محاسبه‌گر خسارت تأخیر تأدیه

مسیر `/calculator/late-payment` از «شروع سریع» صفحهٔ خانه در دسترس است و پس از نصب PWA
بدون اتصال به سرور محاسبه می‌کند. مبلغ دین را با واحد ریال یا تومان وارد کنید؛
هنگام تایپِ مبلغ اصلی و پرداخت‌های جزئی، ارقام خودکار سه‌رقمی جدا می‌شوند
(مثلاً `1000000` به `1٬000٬000` تبدیل می‌شود). مبلغ چسبانده‌شده با ارقام
فارسی/عربی، ویرگول یا فاصلهٔ سه‌رقمی نیز پذیرفته می‌شود. یکی از مبدأها را
انتخاب کنید: **دین عادی** (مطالبهٔ مستند پس از سررسید)، **چک** (تاریخ مندرج در
چک) یا **مبدأ مشخص‌شده در رأی/اجراییه**. برای همهٔ تاریخ‌ها می‌توانید هشت رقم
پیوستهٔ شمسی مانند `14050101` تایپ کنید تا همان لحظه به `1405/01/01` تبدیل
شود، یا از دکمهٔ تقویم، سال/ماه و روز را برگزینید. اگر روز معلوم نیست، فقط
ماه (`۱۴۰۳/۰۱` یا شش رقم پیوسته) را تایپ کنید یا در تقویم «انتخاب ماه بدون روز»
را بزنید؛ در رخدادهای هم‌ماه، ترتیب روزها با هشدار به بررسی پرونده ارجاع می‌گردد.
روز برای ترتیب‌سنجی است، نه ساخت شاخص یا خسارت روزانه. **عدد شاخص همان ماه‌ها** را از *یک سری شاخص بانک مرکزی با
سال پایهٔ مشترک* وارد کنید؛ برای پرداختی که در ماه مبدأ یا مقصد است می‌توان
شاخص را خالی گذاشت تا از شاخص همان ماه استفاده شود. برنامه شاخص‌های رسمی را
خودکار دریافت یا حدس نمی‌زند؛ تا انتشار شاخصِ ماه پرداخت، نمی‌توان رقم قطعی همان
ماه را با شاخص ماه پیشین به دست آورد.

فرمول رأی وحدت رویهٔ ۸۵۰: `دینِ به‌روز = اصل دین × (شاخص ماه پرداخت / شاخص ماه مبدأ)`؛
خسارت، مازاد بر اصل است. در فرض پرداخت جزئیِ محکوم‌به در اجرای حکم، مبلغ هر
پرداخت به نسبت از دینِ به‌روز همان ماه کسر می‌شود (نه صرفاً از اصل). سپس فقط
ماندهٔ تسویه‌نشده ارزش‌گذاری می‌شود. تخصیص پرداخت‌های پیش از حکم/مورد توافق
نیاز به بررسی جداگانه دارد. همهٔ محاسبات با `BigInt` و کسر دقیق انجام می‌شوند؛
مبالغ هر مرحله فقط هنگام نمایش و ماندهٔ نهایی هنگام تسویه به ریال گرد می‌شوند.
تبدیل ریال/تومان و ارقام فارسی/عربی نیز پشتیبانی می‌شود.

این ابزار **استحقاق حقوقی را احراز نمی‌کند** و برای مهریهٔ وجه نقد (تبصرهٔ مادهٔ
۱۰۸۲ قانون مدنی)، ارز خارجی، وجه التزام، سود بانکی یا پرونده‌های دارای شرایط
استثنایی جایگزین بررسی تخصصی نیست. توضیح مبانی، استثناها و شیوهٔ آزمون در
[`docs/LEGAL-REVIEW.md`](docs/LEGAL-REVIEW.md) آمده است.

ساختاریافتهٔ قوانین در `data/sources/structured-laws/` راستی‌آزمایی شده‌اند.

ساختار پوشهٔ سوالات:

```
src/lib/exam/
  types.ts          نوع‌های داده (سوال، وضعیت آزمون، کارنامه)
  categories.ts     جدول توزیع ۱۰۰ آزمون بین ۹ حوزه
  exams.ts          فهرست آزمون‌ها، انتخاب تصادفی سوال، محاسبهٔ نمره
  difficulties.ts   سطوح دشواری مجاز (آسان/متوسط/سخت)
  storage.ts        ذخیرهٔ وضعیت و تاریخچه در localStorage
  questions/
    index.ts        ادغام ۹ فایل و تخصیص شناسهٔ عددی پایدار
    civil.ts  civil-procedure.ts  commercial.ts  criminal.ts
    criminal-procedure.ts  registration.ts  fiqh.ts
    constitutional.ts  probate.ts
```

هر سوال ساختار ثابتی دارد (`question` / `options[4]` / `correctAnswer` /
`difficulty` / `source` — بدون `id`)؛ شناسهٔ عددی هنگام ادغام به ترتیب دسته‌ها
تخصیص می‌یابد و چون سوالات جدید فقط **به انتهای آرایهٔ فایل حوزه‌ای** اضافه
می‌شوند، شناسهٔ سوالات موجود هرگز تغییر نمی‌کند و تاریخچهٔ ذخیره‌شدهٔ کاربران
معتبر می‌ماند.

### رفتار برگزاری

- **انتخاب سوال**: هر «شروع»، ۵ سوال تصادفی و بدون تکرار از دستهٔ همان آزمون
  (الگوریتم Fisher–Yates با تابع تصادفی قابل تزریق برای آزمون‌پذیری).
- **تایمر مقاوم به رفرش**: به‌جای شمارش معکوسِ ساده، مهلت پایان (`deadlineTs`)
  در `localStorage` ذخیره می‌شود؛ پس از رفرش یا بستن صفحه، زمان باقی‌مانده از
  همان مهلت محاسبه می‌شود و با اتمام آن، کارنامهٔ خودکار صادر می‌گردد.
- **ادامهٔ آزمون نیمه‌کاره**: وضعیت (سوالات انتخاب‌شده، پاسخ‌ها، سوال جاری)
  ذخیره می‌شود و صفحهٔ آغاز «ادامهٔ آزمون ذخیره‌شده» را پیشنهاد می‌دهد.
- **کارنامه**: درصد، پیام متناسب، فهرست کامل سوالات با «پاسخ شما / پاسخ
  صحیح» (سبز/قرمز)، مستند قانونی هر سوال، دکمه‌های «تلاش مجدد همین آزمون» و
  «بازگشت به فهرست آزمون‌ها»؛ بهترین درصد و تعداد تلاش‌ها در تاریخچهٔ هر
  آزمون نگهداری می‌شود.
- **محدودسازی کپی متن سوال** (اختیاری) پیاده شده است.

آزمون‌های خودکار این بخش در `tests/exam.test.mjs` است: سلامت بانک (ساختار
سوالات، یکتایی گزینه‌ها، کفایت سوال هر دسته، پراکندگی پاسخ صحیح)، توزیع ۱۰۰
آزمون، منطق انتخاب سوال و نمره، قالب تایمر و رفتار ذخیره‌سازی.

```
  scrape/            اسکریپت‌های Playwright/BeautifulSoup برای تکمیل داده
tests/               آزمون‌های خودکار (داده، جست‌وجو، واحد، PWA، آزمون اختبار)
public/
  data/              داده‌های نسخه‌بندی‌شده (version.json + v/<version>/…)
  sw.js, manifest.webmanifest, icons/
src/
  app/               صفحات (خانه، قوانین، آزمون‌ها، آراء قضایی، ماده، جست‌وجو، نشان‌ها، تنظیمات، گزارش پوشش، محاسبه‌گرها، درباره)
  app/exam/          فهرست آزمون‌ها و صفحهٔ برگزاری هر آزمون (/exam/[examId])
  components/        پوسته برنامه، کارت‌ها، Sheetها، اجزای shadcn-مانند
  components/exam/   برگزارندهٔ آزمون (تایمر، ناوبری سوال، کارنامه)
  lib/exam/          منطق آزمون: دسته‌ها، بانک سوالات، نمره، ذخیره‌سازی
  lib/               پایگاه‌داده، همگام‌سازی، جست‌وجو، نرمال‌سازی، ابزارها
  workers/           Web Worker جست‌وجو
docs/                مستندات داده، نرمال‌سازی، افزودن قانون و بازبینی حقوقی
```

## 🔄 چرخه داده

```
منابع رسمی/آزاد → data/sources/**  →  scripts/build-data.mjs  →  public/data/v<version>/**
                                                                    ↓
                                        همگام‌سازی دلتا (هش هر قانون) در مرورگر → IndexedDB
```

هر قانون یک **هش** دارد؛ برنامه در هر اجرا فقط قوانین تغییرکرده را می‌گیرد. نسخه فعلی:
`public/data/version.json` را ببینید.
