# کتابچه قانون ایران 📚⚖️

وب‌اپلیکیشن موبایلی (PWA) مطالعه، جست‌وجو و مرور قوانین و مقررات جمهوری اسلامی ایران —
**آفلاین، سریع و کاملاً محلی**.

> **جمع‌آوری و تدوین اطلاعات:** وکیل پایه یک دادگستری لیلا آبکه
> **توسعه نرم‌افزار:** [کارن سافت](https://karen-soft.ir)
>
> ⚠️ مرجع رسمی، **روزنامه رسمی جمهوری اسلامی ایران** و **سامانه ملی قوانین و مقررات (qavanin.ir)** است.
> این برنامه ابزار کمکی مطالعه و جست‌وجوست و برای استناد در مراجع قضایی باید متن رسمی بررسی شود.

---

## ✨ چه چیزی در این نسخه هست؟

| ویژگی | توضیح |
| --- | --- |
| **۳۴۵ سند حقوقی / ۷٬۲۷۸ ماده** | ۴۶ سند با متن کامل ماده‌به‌ماده (قانون اساسی — مقدمه + ۱۷۷ اصل، قانون مدنی — ۱۳۳۵ ماده، مجازات اسلامی، آیین دادرسی کیفری و مدنی، تجارت و لایحه اصلاحی، کار، حمایت خانواده، دیوان عدالت اداری، مالیات‌ها، شهرداری، حقوق مؤلفان و…) + **۲۳ سند فقط‌شناسنامه** (متنشان در منابع آزاد نبوده) + **۲۷۶ عنوانِ فهرستی** که فقط نام سند برای آن‌ها ثبت شده است |
| **۲۸۶ نهاد در ۹ گروه** | وزارتخانه‌ها، سازمان‌های دولتی، نهادهای عمومی غیردولتی، نیروهای مسلح، سازمان‌های بین‌المللی، بانک‌ها، دانشگاه‌های دولتی و شرکت‌های دولتی + گروه «شوراها، ستادها و مراجع صادرکننده» |
| **آراء قضایی (اختیاری)** | ۱٬۹۹۸ رأی حقوقی/کیفری/اداری با جست‌وجوی اختصاصی — **در همگام‌سازی عادی دانلود نمی‌شود** و فقط با انتخاب کاربر از صفحهٔ «آراء قضایی» یا تنظیمات دریافت می‌گردد (~۱۲٫۸ مگابایت) |
| **سلسله‌مراتب حقوقی** | موازین شرع ← قانون اساسی ← قوانین عادی ← مقررات دولتی ← مصوبات شوراها ← آرای وحدت رویه ← نظریات مشورتی ← معاهدات و کنوانسیون‌ها |
| **۱۰ دسته موضوعی** | اساسی، مدنی، کیفری، خانواده، تجارت، کار، اداری، آیین دادرسی، مالی، سایر |
| **جست‌وجوی فارسی** | نرمال‌سازی ی/ك، نیم‌فاصله، ارقام فارسی، اعراب؛ جست‌وجو در Web Worker با هدف <۳۰۰ms |
| **۱۰۰٪ آفلاین** | متن قوانین در IndexedDB ذخیره می‌شود؛ پس از نصب، مرور و جست‌وجو بدون اینترنت کار می‌کند |
| **تجربه موبایل** | ناوبری پایین ۶ زبانه، کارت‌های کشیدنی (Swipe)، Bottom Sheet، Pull-to-Refresh، اسکلتون، دارک‌مود، فونت وزیرمتن |
| **ابزارها** | محاسبه‌گر ارث، محاسبه‌گر دیه، یادداشت شخصی، نشان‌گذاری، تاریخچه جست‌وجو، اشتراک‌گذاری بومی |
| **حریم خصوصی** | یادداشت‌ها، نشان‌ها و تاریخچه فقط روی دستگاه شما ذخیره می‌شوند (Local-first) |

## 🧱 پشته فناوری

- **Next.js 14 (App Router)** + TypeScript + Tailwind CSS (طراحی RTL، فونت Vazirmatn به‌صورت self-host)
- **Dexie (IndexedDB)** برای پایگاه‌داده محلی و همگام‌سازی دلتا بر پایه هش
- **MiniSearch** در **Web Worker** برای جست‌وجوی فوری متن + مسیر سریع «ماده ۱۰ قانون مدنی»
- **PWA**: `manifest.webmanifest`، Service Worker با کش پوسته/دارایی/داده، نصب روی صفحه اصلی، Background Sync
- **فونت**: Vazirmatn (SIL OFL)

## 🚀 اجرا

```bash
npm install
npm run dev          # ساخت داده‌ها + اجرای محیط توسعه
```

> پیش‌فرض استقرار روی GitHub Pages است و `basePath` برابر `/Lawbook` تنظیم شده.
> برای اجرا در ریشهٔ دامنه (مثلاً لوکال یا Vercel):
> `NEXT_PUBLIC_BASE_PATH= VERCEL=1 npm run dev`

| فرمان | کار |
| --- | --- |
| `npm run dev` | ساخت داده‌ها و اجرای dev server |
| `npm run build` | ساخت داده‌ها + بیلد تولیدی Next.js |
| `npm run data:build` | ساخت داده‌های عمومی از منابع خام (idempotent) |
| `npm run data:validate` | اعتبارسنجی داده‌ها (ساختار، نرمال‌سازی، ۲۵ آزمون صحت متنی، نهادها) |
| `npm run registry:verify` | تطبیق «فهرست مرجع» با داده‌های ساخته‌شده (چه چیزی موجود/افزوده‌شده/تکراری است) |
| `npm test` | اجرای مجموعهٔ آزمون‌های خودکار (داده، تجزیه‌گرها، جست‌وجو، محاسبه‌گرها، متن فارسی) |
| `npm run verify` | اجرای کاملِ همهٔ بررسی‌ها: ساخت داده، اعتبارسنجی، تطبیق فهرست مرجع، نوع‌ها، لینتر و آزمون‌ها |
| `npm run sources:fetch` | دریافت منابع حجیم از مخزن پژوهشی (codeload.github.com) |
| `npm run extract:legalchatbot` | استخراج عناوین و نهادهای جدید از منبع پژوهشی |
| `npm run icons:gen` | تولید آیکون‌های PWA از SVG (با Sharp) |
| `npm run typecheck` | بررسی نوع‌ها |
| `npm run scrape` | اجرای اسکریپت استخراج از سامانه ملی قوانین (نگاه کنید به `scripts/scrape/`) |

## 📁 ساختار پروژه

```
data/
  curated/           منابع دستی: catalog.json (فهرست و دسته‌بندی)، app-info.json (هویت/اعتبار)، fiqh-rules.json،
                     reference-laws.json (شناسنامه اسناد بدون متن)، entities.json (نهادها و سازمان‌ها)،
                     law-title-index.json (عناوین استخراج‌شده)، entities-extra.json (مراجع استخراج‌شده)
  sources/
    lawcorpus/       متون پاک‌سازی‌شده قوانین (q0..q18)
    iranlegalhub/    منبع کمکی ساخت‌یافته (۴۷ سند)
    iranconstitution/ متن قانون اساسی (CC-BY)
    legalchatbot/    منبع پژوهشی (MIT): فهرست عناوین، نهادها و آراء قضایی
scripts/
  build-data.mjs     ساخت public/data از منابع
  build-cases.mjs    ساخت مجموعهٔ آراء قضایی (قطعه‌بندی‌شده)
  extract-legalchatbot.mjs  استخراجِ فقطِ مواردِ جدید از منبع پژوهشی
  fetch-sources.mjs  دریافت منابع حجیم از codeload.github.com
  validate-data.mjs  اعتبارسنجی داده‌ها
  verify-registry.mjs تطبیق فهرست مرجع با داده‌های ساخته‌شده
  gen-icons.mjs      تولید آیکون‌ها
  lib/               نرمال‌سازی فارسی (fa.mjs)، تطبیق عنوان (match.mjs)، CSV (csv.mjs)
  scrape/            اسکریپت‌های Playwright/BeautifulSoup برای تکمیل داده
tests/               آزمون‌های خودکار (داده، جست‌وجو، واحد)
public/
  data/              داده‌های نسخه‌بندی‌شده (version.json + v/<version>/…)
  sw.js, manifest.webmanifest, icons/
src/
  app/               صفحات (خانه، قوانین، نهادها، آراء قضایی، ماده، جست‌وجو، نشان‌ها، تنظیمات، گزارش پوشش، محاسبه‌گرها، درباره)
  components/        پوسته برنامه، کارت‌ها، Sheetها، اجزای shadcn-مانند
  lib/               پایگاه‌داده، همگام‌سازی، جست‌وجو، نرمال‌سازی، ابزارها
  workers/           Web Worker جست‌وجو
docs/                مستندات داده، نرمال‌سازی، افزودن قانون و بازبینی حقوقی
```

## 🔄 چرخه داده

```
منابع رسمی/آزاد → data/sources/**  →  scripts/build-data.mjs  →  public/data/v<version>/**
                                                                    ↓
                                        همگام‌سازی دلتا (هش هر قانون) در مرورگر → IndexedDB
```

هر قانون یک **هش** دارد؛ برنامه در هر اجرا فقط قوانین تغییرکرده را می‌گیرد. نسخه فعلی:
`public/data/version.json` را ببینید.
